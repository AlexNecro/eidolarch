Eidolarch Help

Eidolarch

v2.2.13 · Local-first intelligent photo curator

Quick start

Add photo folders in ⚙ Settings → Library. Browsing works immediately; AI indexes are built in the background.

Folders, tags and navigation

Folders works like a file gallery. Tags are cumulative and use AND logic. Back/Forward restores window state including folder, tags, search and scroll position.

A zero folder count can currently mean there are no photos directly in that folder even if subfolders contain photos.

Search

Semantic search is restricted by the current folder and selected tags. Similarity numbers are ranking scores, not probabilities.

With relevance colors enabled, weaker results are tinted more red relative to the best results in the current query.

Duplicates and Similar

Duplicates means exact/near copies detected by hashes. A red border marks a photo that belongs to a duplicate group. Similar means visually or semantically close and is not the same as duplicate detection.

Photo viewer

The inspector contains Info, Objects, Similar and Duplicates. Info shows EXIF, file path, tags and user metadata. Objects can be named, but robust person/pet re-identification is still under development.

Selection and file operations

Ctrl toggles items; Shift selects a range. The context menu exposes Similar, Duplicates, Open, Reveal in Explorer, Print, Rename, Copy/Cut and Trash.

Background indexing

Eidolarch builds several indexes in the background: catalog/thumbnails, semantic embeddings, tags, duplicate hashes and detected objects. Progress counters can therefore differ temporarily.

AI, GPU and CPU

Auto mode prefers a compatible GPU and falls back to CPU when needed. CPU mode is valid but initial indexing is slower.

LAN access

The LAN button shows local interface URLs, QR codes and copy/open actions. Read-only access and original downloads can be controlled in Settings.

Multiple windows

Each UI window has independent navigation/search state while sharing one backend, database and index.

Indicators

  • Red border: duplicates exist.
  • Red search tint: weaker relative match.
  • AI: GPU/CPU/API: actual inference backend.
  • Spinner: background work is active.

Keyboard shortcuts

Ctrl+F Search · Ctrl+A Select visible · Ctrl+C/X/V Internal file operations · Delete Trash · F2 Rename · Ctrl+Z/Y Undo/Redo · Alt+Left/Right History · Esc Close/Clear selection.

Privacy

Eidolarch is local-first. Originals stay in place; metadata, thumbnails and embeddings are stored separately.

Troubleshooting

  • No search results: wait for some AI embeddings.
  • Slow indexing: check whether AI shows GPU on a compatible NVIDIA system.
  • Mixed languages: known incomplete localization issue.
  • Folder count 0 with subfolders: count may currently mean direct photos only.

What’s new in v2.1

Photos open in a separate window by default. Duplicate-only mode, folder breadcrumbs, recursive counters, path-on-hover and clearer background-job status were added.

The viewer’s Duplicates tab shows file paths and can move an unwanted copy to the Windows Recycle Bin.
