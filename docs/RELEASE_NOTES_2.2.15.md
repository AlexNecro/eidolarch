# Eidolarch 2.2.15

UI regression-fix release.

## Fixed
- Grid / Cards / Table switch is clickable again.
- Cards duplicate context is populated for all visible cards.
- Duplicate copies in Cards are shown as compact text rows instead of redundant thumbnails.
- Viewer no longer shows a redundant zoom-state label.
- 100% and Fit are styled as mutually exclusive view-mode controls.
- Short control-specific tooltips are restored for 100% and Fit.
- Cards are slightly smaller and use a gentler hover scale so the active border stays visible.
