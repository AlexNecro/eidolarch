# Eidolarch 2.2.12

Search and duplicate-UI update.

## Changed

- Typing `@` in Search now suggests existing named entities.
- `@name` is now an exact entity filter instead of an ordinary semantic query.
- `@name plain text` combines the entity filter with semantic search.
- Multiple entity tokens use AND semantics.
- The hover duplicate action appears directly over the persistent duplicate badge.
- Content/list view shows the current path in bold and several duplicate paths underneath.
- Details shows an explicit localized missing-date label instead of a bare dash.
