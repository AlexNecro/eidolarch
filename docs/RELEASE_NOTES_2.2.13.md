# Eidolarch 2.2.13

UI consistency update.

## Fixed

- Grid / Content / Details now highlight the actually selected view.
- Content mode now loads and shows duplicate paths under the current file path.
- Russian tooltips use localized names for Content and Details.
- Language/theme changes propagate to other open Eidolarch windows.
- Standalone viewer uses the Eidolarch tooltip system instead of browser-native title popups.

## Changed

- Added **Favorites** as a first-class main mode.
- Removed the redundant tile **Info** hover action; normal photo click already opens Info.
- Relationship graph now opens in its own app window.
- Hovering a graph node highlights its incident edges and fades unrelated nodes/edges.
- Clicking a graph node sends that tag selection back to the main window.
- Restored the more detailed Help emblem.
